# ComfyUI MiniMax H3 Prompt Synthesizer

A customized ComfyUI node for MiniMax H3 prompt engineering, visual side-by-side prompt helper, and external web image drag-and-drop support.

## 🚀 Features

* **Multi-dimensional Prompt Synthesis**: Supports bilingual camera angles, optics, shot types, and movement parameters.
* **Side-by-Side Web Tools**: Quick access buttons to search resources right next to your workflow.
* **Safe Image Drag & Drop**: Drag images directly into node widgets with backend SSRF protection and image file verification.
