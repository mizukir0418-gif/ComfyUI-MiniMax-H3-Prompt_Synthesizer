# ComfyUI MiniMax H3 Prompt Synthesizer

A customized ComfyUI node for MiniMax H3 prompt engineering, visual canvas annotation, side-by-side prompt helper, and external web image drag-and-drop support.

## 🚀 Features

* **Multi-dimensional Prompt Synthesis**: Supports bilingual camera angles, optics, shot types, and movement parameters.
* **Interactive Canvas Annotator**: Built-in stage padding (chroma green), sticker library, subject/action/shot-frame tags, and dual output switches (`clean_image` / `annotated_image`).
* **Side-by-Side Web Tools**: Quick access buttons to search resources right next to your workflow.
* **Safe Image Drag & Drop**: Drag images directly into node widgets with backend SSRF protection and image file verification.

## 📦 Installation

1. Navigate to your ComfyUI custom nodes directory and clone this repository:
   ```bash
   cd ComfyUI/custom_nodes
   git clone https://github.com/mizukir0418-gif/ComfyUI-MiniMax-H3-Prompt_Synthesizer.git
   ```
2. Restart ComfyUI and refresh your browser page.
